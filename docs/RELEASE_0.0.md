## 本次范围

- 重新核对当前源码功能，并以 [FEATURES.md](FEATURES.md) 记录实现和验证边界。

## 已知问题和限制

1. H24T7 曾报告软件切源后持续花屏、切回 DP 恢复。当前对能力表与读数矛盾的高级功能保持只读；本轮不再次切源。
2. VGN 三项实验性写入默认关闭。已有探针写入/回读/改回记录，物理效果和断电保存未完成验收。不要把该开关理解为完整驱动适配。
3. N9 V2 的 EQ 产品写入未开放。开发探针曾覆盖测试设备 Custom 曲线第 0 点，原始值未能恢复，见 [PRIVATE_WRITE_CANDIDATES_2026-10-19.md](PRIVATE_WRITE_CANDIDATES_2026-10-19.md)。探针不作为日常应用运行入口。
4. L98 的电量、RGB、改键尚未适配；系统名称与接口识别不足以证明这些能力。
5. 真实多屏、重复拔插、充电和有线/无线切换、睡眠/唤醒、第二台无开发环境 Windows 11 电脑仍待验收。
6. 当前 Windows EXE 未签名。Qt 对应源码及构建材料和 MSVC 再分发材料仍需核定；本次 GitHub 先发布应用源码，不附未经完成核定的运行库分发包。
