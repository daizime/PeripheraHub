# 0.0 发布准备与功能边界

核对日期：2026-10-19。当前版本为 **0.0 初始预览版**，首次公开应用源码。此前内部 Demo 的版本建议不再作为本版发布要求；未完成的硬件验收继续保留。

## 已有实现

- 核心、Qt 组件和模拟集成测试纳入主 CTest，独立 DeviceGrid 已包含主题依赖。
- Qt 资源生成文件的路径编码已规范化，不关闭编译警告来隐藏问题。
- 数据目录单实例保护、可写性检查、档案原子提交和失败保留。
- 显示器矛盾枚举保持只读，重连恢复不自动切源；输入/输出音量独立排队。
- VGN F2 Master+ 和 N9 V2 ULTRA 的限定接口读取；记录实际值，未知和历史值明确区分。
- VGN 档位 DPI、回报率、当前档位的白名单写入已接到默认关闭的实验性开关后；已有独立探针往返记录。
- 唤醒消息后的延迟强制重扫、托盘调节与低电量提醒。
- 构建输入摘要、EXE 哈希和包清单检查；源码归档排除本地设备数据和研究下载。

## 发布范围

GitHub 先发布应用源码、必要资源和构建说明，并以 v0.0 标记初始预览。Windows 候选包可本地生成；在硬件验收、干净机器测试、Qt 对应源码与构建材料和 MSVC 分发材料核定完成前，不作为已完成这些验收的正式运行库分发包。

本轮实际验证结果见 [RELEASE_0.0.md](RELEASE_0.0.md)，后续实机步骤见 [ACCEPTANCE_CHECKLIST.md](ACCEPTANCE_CHECKLIST.md)。
